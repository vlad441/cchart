Custom Chart x.x.x-x Example

Опции:
  • absolute: <bool> Абсолютная шкала
  • legend: <bool> Отобразить значения
  • simple: <bool> Без интерактива
  • setka: <bool> сетка
  • name: <String> Название графика
  • names: <Array[NameX, NameY]> Имена координат
  • color: <String> Цвет линии
  • colors: <Array> Цвет каждой линии
  • delta(min/max)val: <int> тонкая настройка дельты - разница макс/мин
  • columns: <int> Кол-во колонок
Функции:
  • chart.draw(dataSets=[]): Нарисовать график
  • chart.renderFunc(fn, limit = 10, step = 1, start = 0): Вычислить и нарисовать fn(x) на графике
  • chart.randomizer(limit = 10): Нарисовать график с рандомными значениями до лимита x
  • chart.clear(): Очистить график
  • CustomChart.calcFunc(fn, limit = 10, step = 1, start = 0): Вернуть dataSet от fn(x)
